# Data Analysis Methodology

## Stage 1: Data Acquisition

Use simulated datasets with documented structure
and generation procedures.

## Stage 2: Exploratory Data Analysis

Inspect rows, columns, data types, distributions,
summary statistics, and data quality.

## Stage 3: Data Cleaning

Check duplicates, missing values, invalid records,
out-of-range values, and inconsistent formatting.

## Stage 4: Data Transformation

Create calculated features, aggregates,
date features and grouped summary tables.

## Stage 5: Statistical Analysis

Apply mean, median, variance, standard deviation,
quartiles, correlation, and domain-specific tests.

## Stage 6: Visualization

Use line plots, bar charts, histograms,
box plots, scatterplots, and heatmaps
where appropriate.

## Stage 7: Interpretation

Explain what each calculation and chart means,
its limitations, and the additional evidence
needed for real-world recommendations.

## Stage 8: Reporting

Export data summaries, high-resolution charts
and PDF reports with analytical explanations.

## Key Limitation

These are simulated examples, and statistical
relationships are not inherently causal.
