# Testing Evidence

## Suggested Tests

1. Run every project notebook from a fresh kernel.
2. Check that dataset loading succeeds.
3. Check required columns and data types.
4. Verify missing-value and duplicate handling.
5. Validate calculation formulas and allowed ranges.
6. Confirm all intended visualizations are saved.
7. Open and inspect every PDF report.
8. Verify the generated summary tables.
9. Compare reported findings to notebook calculations.
10. Record the result of every test.
