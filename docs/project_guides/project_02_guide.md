# Project 2: Student Performance Analysis

## Domain

Education

## Objective

Analyze academic performance, pass rates, subjects and attendance.

## Dataset

Simulated educational dataset.
See the project's data directory for available files.

Data validation, median imputation, descriptive statistics, correlation and Welch t-test.

Pass/fail rates, subject scores, class comparisons and attendance relationships.
