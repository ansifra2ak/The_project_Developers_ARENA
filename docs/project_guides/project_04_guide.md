# Project 4: Healthcare Data Analysis

## Domain

Healthcare

## Objective

Analyze hospital visits, waiting times, stays and patient satisfaction.

## Dataset

Simulated educational dataset.
See the project's data directory for available files.

## Methodology

Data cleaning, department aggregations, distributions, correlation and Welch t-test.

## Analysis and Reporting

Department waiting times, visit volumes, satisfaction and length-of-stay patterns.

`healthcare-data-analysis/project4_healthcare_analysis/notebooks/healthcare_analysis.ipynb`
